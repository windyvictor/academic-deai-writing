# 误改防线：已证伪特征与学术体裁例外

把「读着像 AI」当作改写理由，会把论文改坏。下面两类特征一律不作为删改依据：一类在对照复测中方向反转或无差异，一类是科研体裁本身的正常写法。

本文件的方法依据来自 `lieflat-less-ai-tone`（CC BY-NC 4.0，作者 shiujan）的两轮实测：第一轮 629 篇对照，第二轮 270 对同题同事实配对复测。其语料是中文自媒体与叙事文本，本技能只重述「哪些特征被证伪、哪些改动会误伤」，不引用其频率数值作为论文语料的判据，也不复制其脚本与规则原文。下文第二节的体裁例外由本技能补充，不属于原研究的结论。

独立的英文学术语料研究给出同向结果：Desaire 等（2023，[PMC10328544](https://pmc.ncbi.nlm.nih.gov/articles/PMC10328544/)）用 20 个文体特征区分人类科学家与 ChatGPT 撰写的学术引言，其中 18 个特征在人类一侧更多，包括更长的段落、更大的句长变化、问号／破折号／括号／分号／冒号、`however / but / although / because / this`、数字与专有名词。该研究测试集小，作者自述贡献是「方法而非通用模型」；可迁移的是方向，不是百分点。在上表列出的这几项特征上，中文自媒体语料与英文学术引言语料结论同向，说明删这些写法缺少依据；这不等于两套语料在所有特征上一致。出处与证据强度见 `evidence-and-policy.md`。

## 一、实测已证伪，不因「像 AI」删改

| 特征 | 复测结论 | 在科研文本中的正常用途 |
|---|---|---|
| 序数词小标题、章节编号 | 方向反转，人类比 AI 更常用（8.6% vs 4.9%） | 「1 引言 / 2 方法」、基金申请书的「一、研究内容」是版式要求，结构不改动 |
| 「这意味着 / 这表明 / 这说明」式复述 | 三项口径全反向，人类更多 | 推导中把上一步结果接到下一步结论，承担必要逻辑连接 |
| 空转句引列表（「如下：」+ 列表） | 方向反转，人类高一个量级 | 方法步骤、参数表、伪码、实验条件的引出句 |
| 概括替代（同段已有具体数值） | 对称口径净零，精确数字保留 98% | 先给结论再给数据的常规段落组织 |
| 精确数字堆砌 | 同事实配对后差异消失（δ −0.06） | 样本量、超参数、误差值、统计量必须完整保留 |
| 漂亮词黑名单（赋能 / 闭环 / 抓手等） | δ +0.10，不显著 | 按词表删除属于无标准改写；评价性表述另按「贡献由证据体现」判断 |
| 名词化、明喻、设问、模糊量词、「首先 / 其次 / 总之」 | \|δ\| < 0.2 | 方法步骤常用「首先 / 其次」；被动式名词化在学术文体中自然存在 |
| 句长、段长「不够参差」 | 两轮配对复测均无差异 | 不为节奏改句长、不拆段落；机械参差化比不改更糟 |
| 「其」字 | 人类更多 | 常规回指，不删 |
| 问句、设问、问句小标题 | 人类远多于 AI | 研究问题式小标题、推导中的设问属于作者写法 |
| 被动句 | 人机无差异 | 「样本被随机分为三组」是标准方法表述 |
| 反复写全称、少用代词 | 人类更多 | 术语重复是术语一致，不是词汇贫乏 |

## 二、学术体裁例外：通用规则在此不适用

通用中文去 AI 味规则里可改的写法，在论文里常常是必要结构。命中后先按本表判断，再决定是否改。

| 通用规则 | 学术稿件中的处置 |
|---|---|
| 衔接连环过长 → 打断衔接、制造自然跳跃 | 论证链必须紧扣，不制造跳转。只处理「有连接词但标称的逻辑关系不成立」的接口，改写为真实关系，不删掉衔接本身 |
| 句首连接词当路标 → 移到主语后 | 论证需要显式路标时保留「因此」「然而」；显式关系优先于文风 |
| 同义重命名 → 统一回原名词 | 先确认是否同一概念。术语首现「又称 X」、方法／算法／模型的区分、不同变量的近义表述不算漂移。确认漂移后统一回本领域标准术语，不改概念 |
| 顿号罗列过密 → 概括或打散 | 条件、参数、数据集、指标、假设清单必须完整列出，不概括、不打散 |
| 提示语冒号 → 删提示语 | 定义式冒号、公式引出、引语式、列表引出全部保留；只有「结论宣告 + 展开论证」一类考虑改写 |
| 相邻句 / 三连同构 → 打散其中一句 | 三个并列实验条件、三条假设、并列定理属内容结构，不改；只有句法逐字复刻且无内容必要时才动其中一句 |
| 分号、破折号 → 拆句或换标点 | 数学定义、公式条件、列举层级中承担必要关系时保留 |
| 比喻、拟人化喻体 → 换平实陈述 | 贴切度模型间共识低，交人审；论文里出现时按作者原意保留 |
| 强加「我 / 你」、删小标题、改口语 | 学术、公文体裁不加强加人称；标题层级、章节顺序、段落顺序、列表、表格、引用、代码块位置原样保留 |

## 三、判读纪律

- **命中不等于改。** 单个词、单个句式不构成修改理由。回到上下文确认是否空泛、重复、歧义或与证据强度失配，通顺准确的表达保留。
- **分布特征只报告，不逐句改。** 句长离散度、小节长度方差、小标题密度、词汇多样性是整篇属性，逐句改必然过度。
- **研究语料显著不等于单篇显著。** 不宣称「本文统计显著」，不据此判断作者身份或推断生成模型。
- **不同轮次、不同分母的指标不混算倍数。** 每千字与每百段、第一轮抽样与配对复测各有口径。
- **保留要举证。** 保留一处命中时，指出该术语、引用、公式、逻辑连接或版式作用为何不可替换，或说明最小改写会损失什么信息。不写「读着自然」「只有一处」当作理由。
- **判不准就留痕。** 标「待核 / 人审」并列出原句，不归零、不静默删项。诊断模式的报告口径见 `diagnosis-protocol.md`。
- **改前锁定事实锚点，改后逐项核对。** 数字、否定、比较对象、条件、引用、术语、确定程度，见 `preservation-and-evaluation.md`。
